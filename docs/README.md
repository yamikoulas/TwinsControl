# Introduction

Welcome to the official documentation for **TwinsControl**.

**TwinsControl** is a modern, high-performance cheat inspection (screenshare / freeze) plugin designed for Minecraft server networks running on Paper, Purpur, Spigot, and Pufferfish.

---

## Why TwinsControl?

Server moderation can often be chaotic, especially when handling suspected cheaters. Players might combat-log, drop valuable items, spam malicious commands, or exploit vulnerabilities while being inspected.

TwinsControl eliminates these problems by providing an all-in-one, secure inspection workflow:

* **Complete Isolation:** Players are instantly frozen, rendered invulnerable, and prevented from taking any disruptive actions.
* **Smart Automation:** From auto-punishing combat loggers to managing confession discounts, TwinsControl handles repetitive moderation tasks automatically.
* **Modern Visuals:** Live BossBars, ActionBars, Title alerts, and HEX gradients keep both the player and staff clearly informed.
* **High Performance:** Built with zero internal NMS (Net.Minecraft.Server) dependencies, ensuring clean compatibility across Minecraft 1.16.5 up to 1.21.x+.
